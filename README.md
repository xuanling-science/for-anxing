# 给安行的生日惊喜

一个无须安装依赖、无须构建的静态生日网页，支持电脑和手机。

## 本地打开

双击 `index.html` 即可。请将 `index.html`、`style.css`、`script.js` 保存在同一个文件夹。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `birthday-anxing`。
2. 打开仓库的 **Add file → Upload files**，将本文件夹内的文件上传到仓库根目录并提交。根目录应直接包含 `index.html`。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中将 **Source** 选为 **Deploy from a branch**，将分支选为 **main**，文件夹选为 **/ (root)**，点击 **Save**。
5. 等待部署完成，在 Pages 页面获取网址，一般为 `https://你的用户名.github.io/birthday-anxing/`。仓库名不同，网址中的路径也会不同。

一般使用公开仓库即可免费发布。生日礼物链接与仓库中的祝福文字会公开可见。

## 互动

- 点击礼物盒或“拆开礼物”：礼物消失，蛋糕渐显，生日歌开始播放。
- 点击信封：向下展开信纸；再次点击可以收起。
- 点击背景或页面空白：出现不同大小、不同方向的烟花与彩色粒子。
- 右上角音乐按钮：开启或关闭音乐。切到其他标签页或锁屏后暂停，回来可手动开启。

音乐为 Web Audio 本地合成的《生日快乐》八音盒风格旋律，无人声，无外部音频依赖。浏览器要求首次播放由点击触发；静音模式、媒体音量或浏览器设置可能影响声音。

所有插画均为内置 SVG，背景及互动均为本地 CSS / JavaScript，不依赖字体、图片 CDN 或外部接口。

## 修改文字

在 `index.html` 中修改信纸文字；打开礼物后的标题和副标题位于 `script.js` 的 `openGift()` 函数中。颜色与动画可在 `style.css` 中调整。
